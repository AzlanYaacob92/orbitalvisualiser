    What this model simplifies
    • Only the angular shape is drawn. Radial nodes (for example inside 2s, 3s and 3p) are not shown.
    • These are the real orbitals (px, py, pz, dxy …), which are combinations of the complex orbitals labelled by ml. Each real orbital is tied to an ml value for bookkeeping only.
    • Orbital size grows with n as n0.75. Real average radii grow roughly as n2, so this keeps the order of sizes but compresses the ratios.
    • The vertical energy axis is schematic: the order is right, the gaps are not to scale.
    • Scope: 1s to 5p (up to xenon, 54 electrons). No f orbitals.
